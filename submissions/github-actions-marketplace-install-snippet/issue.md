# Issue: Actions Marketplace installation snippet in workflow editor has bad indentation and causes YAML errors

## Description

When you open an action from the workflow editor (Actions → Set up a workflow yourself → search for an action), the **Installation** snippet shown in the Marketplace panel is hard to read and produces syntax errors when pasted into an empty workflow file. The snippet appears to be auto-generated by GitHub (it does not come from a file in the action repo; see e.g. [kameshsampath/antora-site-action](https://github.com/kameshsampath/antora-site-action)). The snippets shown when clicking **Install** on the full Marketplace listing page look correct; the workflow-editor Installation view does not.

## Problems

1. **Inconsistent indentation:** The `- name: …` line is shown with much more leading indentation than the rest of the step. The following lines (`# You may pin…`, `uses:`, `with:`, etc.) are at a shallower indent. So the snippet does not form one coherent YAML step—the step body is not indented under the step.

2. **Comments break visual flow:** A commented-out `# uses: owner/action@commit` line appears immediately above the real `uses: owner/action@version` line. Having two “uses” lines (one comment, one real) with different refs is confusing and interrupts scanning the snippet.

3. **Pasting causes errors:** When the snippet is pasted into an empty workflow file, the editor reports YAML errors (e.g. “Unexpected scalar token in YAML stream” on the `uses:` line). That’s consistent with the snippet being invalid at the paste location: either because it’s only a step fragment and must live under `jobs.<id>.steps`, or because the displayed indentation is wrong so the parser sees `uses:` at the wrong level.

## Expected behavior

- The Installation snippet should use consistent indentation so that the step is one valid YAML block (e.g. `- name:` and all its siblings at the same indent, then `uses:` and `with:` indented under that step).
- Consider reducing comment clutter in the snippet (e.g. omit or shorten the “pin to exact commit” comment so it doesn’t sit directly above the `uses:` line), or add a one-line note that the snippet is a single step and must be pasted under `jobs.<job_id>.steps:`.
- Ideally the workflow-editor Installation snippet should match the quality of the snippet shown when clicking **Install** on the action’s full Marketplace page.
